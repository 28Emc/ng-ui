# ExpandableCard

Tarjeta que puede colapsarse o expandirse para mostrar más detalle. Se controla por click o tecla Enter (el disparador es un `button` nativo), con animación suave al desplegar el contenido.

## Uso

El estado es un `model` (`open`), por lo que puede persistirse enlazándolo de forma bidireccional.

<Source
  code={`<ui-expandable-card
  title="Detalles del pedido"
  subtitle="Haz clic para expandir"
  [(open)]="orderOpen"
>
  <p class="text-sm text-muted">Contenido colapsable.</p>
</ui-expandable-card>`}
  language="html"
/>

| Input      | Tipo      | Descripción                          |
| ---------- | --------- | ------------------------------------ |
| `title`    | `string`  | Título de la tarjeta (obligatorio)   |
| `subtitle` | `string`  | Subtítulo opcional bajo el título    |
| `open`     | `boolean` | Estado expandido/colapsado (`model`) |
