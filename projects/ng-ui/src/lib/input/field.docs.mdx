# Field

Contenedor de formulario que agrupa etiqueta, control proyectado, texto de ayuda y mensaje de
error. Gestiona la accesibilidad automáticamente: el `label` envuelve el control proyectado y los
ids de `hint`/`error` se propagan al `aria-describedby` del control mediante `FIELD_CONTEXT`.
