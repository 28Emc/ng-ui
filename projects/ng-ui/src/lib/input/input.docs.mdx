# Inputs

Grupo de campos de formulario: `Input`, `Textarea`, `Select`, `Label`, `Field`, `FieldError`,
`MaskedInput` y `PasswordStrengthMeter` (estos dos últimos documentados en su propia página). Los
controles implementan `ControlValueAccessor`, por lo que funcionan con `formControlName`, `ngModel`
o formularios reactivos.

## Inputs compartidos (Field)

| Input      | Tipo             | Descripción                        |
| ---------- | ---------------- | ---------------------------------- |
| `label`    | `string`         | Etiqueta visible                   |
| `hint`     | `string`         | Texto de ayuda bajo el control     |
| `error`    | `string \| null` | Mensaje de error (borde/ring rojo) |
| `required` | `boolean`        | Marca el label con asterisco       |

## Inputs de los controles

`Input`, `Textarea`, `Select` y `MaskedInput` comparten estos inputs de atributos HTML:

| Input          | Tipo      | Descripción                         |
| -------------- | --------- | ----------------------------------- |
| `id`           | `string`  | Atributo `id`                       |
| `name`         | `string`  | Atributo `name` (para envío nativo) |
| `autocomplete` | `string`  | Atributo `autocomplete`             |
| `invalid`      | `boolean` | Estado de error (borde/ring rojo)   |
| `disabled`     | `boolean` | Deshabilitado                       |

> En `Combobox`, `Multiselect`, `DatePicker`, `TimePicker` y `DateRangePicker` el atributo
> `autocomplete` está fijo en `"off"` y los pickers de fecha/hora usan `inputmode="numeric"` porque
> su máscara inserta los separadores automáticamente.
