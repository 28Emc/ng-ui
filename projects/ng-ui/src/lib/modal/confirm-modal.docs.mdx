# ConfirmModal

Modal de confirmación accesible con descripción, botones de confirmar/cancelar y variante de
peligro. Emite `confirm` y `cancelled`. Cierra con Escape o clic en el backdrop.

## Uso

<Source
  code={`<ui-confirm-modal
  [open]="open"
  title="Eliminar usuario"
  description="Esta acción no se puede deshacer."
  confirmLabel="Eliminar"
  danger
  (confirm)="onConfirm()"
  (cancelled)="onCancel()"
/>`}
