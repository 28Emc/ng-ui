# Pagination

Paginación con elipsis inteligente, botones anterior/siguiente e información
del rango mostrado. El estado es un `model()` bidireccional.

## Uso

<Source
  code={`<ui-pagination
  [(page)]="page"
  [pageSize]="10"
  [total]="totalItems"
/>`}
  language="html"
/>

| Input          | Tipo      | Descripción                     |
| -------------- | --------- | ------------------------------- |
| `page`         | `number`  | Página actual (bidireccional)   |
| `pageSize`     | `number`  | Ítems por página (default `10`) |
| `total`        | `number`  | Total de ítems                  |
| `siblingCount` | `number`  | Páginas visibles por lado (`1`) |
| `showInfo`     | `boolean` | Muestra "Mostrando X–Y de Z"    |
| `ariaLabel`    | `string`  | Etiqueta accesible del nav      |
