# PasswordStrengthMeter

Campo de contraseña con barra de fuerza y criterios visuales. Implementa
`ControlValueAccessor`, por lo que funciona con `formControlName`, `ngModel` o formularios reactivos.

- Evalúa 5 reglas: longitud mínima, minúsculas, mayúsculas, números y símbolos.
- Barra segmentada que refleja el nivel: **Débil**, **Media**, **Buena** o **Fuerte**.
- Lista de criterios con check visual (ocultable con `showCriteria`).
- Ícono de visibilidad para mostrar u ocultar el texto.

## Inputs

| Input          | Tipo      | Descripción                                          |
| -------------- | --------- | ---------------------------------------------------- |
| `placeholder`  | `string`  | Placeholder del campo (default `Contraseña`)         |
| `id`           | `string`  | Atributo `id` del input                              |
| `invalid`      | `boolean` | Estado de error (borde/ring rojo)                    |
| `disabled`     | `boolean` | Deshabilitado                                        |
| `showCriteria` | `boolean` | Muestra la lista de criterios (default `true`)       |
| `autocomplete` | `string`  | Atributo `autocomplete` (default `current-password`) |

## Utilidades exportadas

`password-strength.utils` exporta `evaluatePassword` (devuelve `checks`, `score` y `level`),
`PASSWORD_CRITERIA`, `PASSWORD_LEVEL_LABELS` y `PASSWORD_SEGMENTS` para reutilizar la lógica de
evaluación fuera del componente.
