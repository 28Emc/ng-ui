## Uso

<Source
  code={`<ui-progress [value]="progress" label="Cargando…" />
<ui-progress [indeterminate]="true" size="lg" />`}
  language="html"
/>

| Input           | Tipo                   | Descripción            |
| --------------- | ---------------------- | ---------------------- |
| `value`         | `number`               | Valor 0–`max`          |
| `max`           | `number`               | Máximo (default 100)   |
| `size`          | `'sm' \| 'md' \| 'lg'` | Grosor                 |
| `indeterminate` | `boolean`              | Modo indeterminado     |
| `label`         | `string`               | Texto junto a la barra |
