## Uso

<Source
  code={`<ui-stepper
  [steps]="3"
  [labels]="['Paso 1', 'Paso 2', 'Paso 3']"
  [(activeIndex)]="index"
/>`}
  language="html"
/>

| Input         | Tipo       | Descripción            |
| ------------- | ---------- | ---------------------- |
| `steps`       | `number`   | Cantidad de pasos      |
| `labels`      | `string[]` | Etiquetas de cada paso |
| `activeIndex` | `number`   | Paso activo (two-way)  |
