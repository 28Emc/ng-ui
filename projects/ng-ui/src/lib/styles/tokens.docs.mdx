# Design Tokens

`ng-ui` está construido sobre [Tailwind CSS v4](https://tailwindcss.com) y define su sistema de
diseño como tokens en `src/lib/styles/theme.css`. Los componentes consumen estas variables, por lo
que tu aplicación puede re-tematizarlos redefiniendo los tokens en tu propio CSS.

## Color

Paleta de marca (teal/verde) con escala 50–900:

| Token                  | Valor     |
| ---------------------- | --------- |
| `--color-brand-500`    | `#15a18b` |
| `--color-brand-600`    | `#0c8b7c` |
| `--color-brand-700`    | `#0b7064` |
| `--color-accent-gold`  | `#bfa23a` |
| `--color-accent-coral` | `#c2706a` |
| `--color-accent-purple`| `#7e6cc0` |
| `--color-accent-blue`  | `#6f86c9` |

La escala `brand-*` alimenta los utilitarios `bg-brand-500`, `text-brand-700`, etc. usados en toda
la librería. Los estados semánticos (`success`, `warning`, `info`, `danger`, `muted`) se definen en
el mismo bloque.

| Token          | Uso                   |
| -------------- | --------------------- |
| `--shadow-soft`| Superficies default   |
| `--shadow-card`| Tarjetas y modales    |
| `--shadow-pop` | Menús y tooltips      |

## Animación y densidad

El tema define keyframes (`fade-in`, `slide-up`, `scale-in`, `pop`, `indeterminate-short`) y
duraciones/curvas estándar. Además expone dos *custom variants* para densidad:

- `density-compact` → activa con `[data-density="compact"]`
- `density-spacious` → activa con `[data-density="spacious"]`

Los componentes (p. ej. `ui-button`) leen `[data-density]` desde su propio atributo.
