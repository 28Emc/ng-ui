## Uso

<Source
  code={`<ui-table
  [columns]="columns"
  [data]="rows"
  [pageSize]="10"
  [striped]="true"
  [trackBy]="trackById"
  (rowClick)="onRow(row)"
/>`}
  language="html"
/>

| Input      | Tipo               | Descripción                                          |
| ---------- | ------------------ | ---------------------------------------------------- |
| `columns`  | `TableColumn[]`    | Definición de columnas (`{ key, label, sortable? }`) |
| `data`     | `T[]`              | Filas                                                |
| `pageSize` | `number`           | Filas por página                                     |
| `striped`  | `boolean`          | Rayado zebra                                         |
| `trackBy`  | `(row) => unknown` | Función de tracking                                  |
| `rowClick` | `Output`           | Emite al hacer click                                 |
